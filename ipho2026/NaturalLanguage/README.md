# GPT-5.6 Sol natural-language theory submission

This directory contains the three Markdown solutions generated by separate
answer-blind Humanize RLCR runs using GPT-5.6 Sol at maximum reasoning effort,
plus a source-level grading audit against the official IPhO 2026 marking
schemes.

## Files

- `T1_solution.md` — Theory Problem 1
- `T2_solution.md` — Theory Problem 2
- `T3_solution.md` — Theory Problem 3
- `GRADING_REPORT.md` — official-scheme grading audit

The worker environments had access to their own problem statement and
figures, but not to official solutions, marking schemes, grading reports,
prior submissions, sibling workspaces, or general internet sources. Official
materials were used only by a separate post-solution grading audit and were
never exposed to the answer-generating workers.
