# IChO 2026 T9-A1

## Answer

Beta-cyclodextrin contains seven glucose-derived units. In the cyclic molecule,
each unit is joined to the next, so there are seven glycosidic bonds. Formation
of each glycosidic bond is a condensation that removes one molecule of water.
Thus the molecular composition can be written as

\[
7\,\mathrm{C_6H_{12}O_6}-7\,\mathrm{H_2O}
=\mathrm{C_{42}H_{70}O_{35}}.
\]

The periodic table supplied with the paper gives
\(M(\mathrm H)=1.008\ \mathrm{g\,mol^{-1}}\) and
\(M(\mathrm O)=16.00\ \mathrm{g\,mol^{-1}}\). Therefore

\[
M(\mathrm{H_2O})=2(1.008)+16.00=18.016\ \mathrm{g\,mol^{-1}},
\]

and, using the stipulated \(M(\text{glucose})=180.16\ \mathrm{g\,mol^{-1}}\),

\[
\begin{aligned}
M(\beta\text{-CD})
  &=7M(\text{glucose})-7M(\mathrm{H_2O})\\
  &=7(180.16)-7(18.016)\\
  &=\boxed{1135.008\ \mathrm{g\,mol^{-1}}}.
\end{aligned}
\]

The required three-significant-figure report is therefore

\[
\boxed{M(\beta\text{-CD})=1.14\times10^3\ \mathrm{g\,mol^{-1}}}.
\]

The scientific notation is intentional: it makes all three significant digits
unambiguous. No intermediate value was rounded.
