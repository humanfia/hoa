# IOI 2026 Day 1 solutions

Submission-ready C++ solutions for the three IOI 2026 Day 1 tasks:

- `ballmachine.cpp` — Ball Machine
- `monuments.cpp` — Monuments
- `tiling.cpp` — Tiling Game

Each file implements the exact contestant API from its official attachment.
The files are intended to be submitted separately with the corresponding task
grader and header.

The solutions were developed and independently reviewed without access to
grading or hidden tests. Validation used only the official contestant
attachments and self-authored tests.

For Ball Machine, the achieved full-score resource bounds are `K <= 15`,
`B <= 34`, `K + B <= 43`, and at most `18,000` calls to `insert`.
