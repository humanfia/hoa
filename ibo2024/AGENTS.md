# IBO 2024 solution project instructions

- Work entirely offline. Do not use web search, browsers, network tools, remote APIs, or external downloads.
- Treat only the two official English IBO 2024 PDFs in `source/` as authoritative. Each PDF contains the official answer and explanation section after the question section.
- Write natural-language biology solutions in Markdown. Do not use Lean or formal-proof syntax.
- Keep prose clear and complete rather than artificially terse. Explain every statement A-D, including why false statements fail.
- Preserve the official truth pattern exactly. If your independent reasoning appears to conflict with the official key, state the issue in the problem file instead of silently changing the key.
- One solver worker owns exactly one independent exam task and writes exactly one file under `solutions/part-a/` or `solutions/part-b/`.
- Do not modify another worker's problem file.
- Use two-digit filenames: `q01.md` through `q50.md`.
- Each problem file must contain: problem/topic title, official answer pattern, and separate natural-language reasoning for A, B, C, and D.
- Do not copy the official explanation verbatim. Paraphrase it and fill in any reasoning needed to make it understandable.
