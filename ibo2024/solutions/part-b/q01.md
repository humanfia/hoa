# Part B — Task 1

*Dichotomous keys: path length, identification capacity, and phylogeny*

**Official answer: A — False; B — True; C — True; D — False.**

## Reasoning

**A — False.** Morphological complexity does not determine how many steps an organism takes through this key. Because the tree is complete and has no terminal branches before level 10, every identification follows a path from the level-1 root to a terminal node at level 10. Such a path contains exactly nine true-or-false decisions, so an organism that can be identified by this key will not require more than nine steps merely because its morphology is more complex than that of X.

**B — True.** Each decision has two possible outcomes, so the number of nodes doubles at every new level. With the root at level 1, the terminal level contains $2^{10-1}=2^9=512$ nodes. If every terminal node identifies a different species, the key can therefore distinguish at most 512 species. There is an arithmetic error in the official explanation: it prints $2^0+2^1+\cdots+2^9=512$, but that sum is 1023 and counts all nodes in the tree. The stated answer remains correct because only the $2^9$ terminal nodes represent final identifications.

**C — True.** From a particular node at level 3, there are seven remaining branchings before level 10, giving $2^{10-3}=2^7=128$ possible terminal identifications below that node. From a node at level 5, there are five remaining branchings, giving $2^{10-5}=2^5=32$ terminal identifications. Thus the level-3 node has $128/32=4$ times as many possible final outcomes.

**D — False.** A dichotomous identification key is organized around whichever diagnostic characters its designer chooses; it is not necessarily a phylogenetic tree. Similar answers to early morphological questions can result from retained ancestral traits or convergent evolution, and close relatives can differ in a character used early in the key. Consequently, the step at which two identification paths separate cannot be inferred with certainty from how recently the taxa shared a common ancestor. Indeed, in a tree that did directly represent ancestry, closer relatives would normally separate later, not earlier, than more distant relatives.
